# 搭友 · 基于大模型的校园互助组队与智能匹配 Web 平台

一个面向在校大学生的校园互助与组队 Web 应用（移动端优先）。目标是让校园组队和互助信息结构化、可筛选，并在 AI 辅助下完成需求整理、匹配推荐和招募文案生成。

## 当前进度（v0.1）

- [x] 首页需求列表 + 关键词搜索 + 多品类标签筛选
- [x] AI 匹配入口强化（首页居中主卡片 + 独立匹配页）
- [x] 发布需求表单（找队友/互助/学习搭子/游戏搭子/拼车/找室友/找 CP 标签）+ 本地草稿生成
- [x] 个人中心：可编辑昵称、专业、年级、性别、年龄、MBTI、心情、签名、技能标签
- [x] AI 匹配页（规则匹配基线，后续接入大模型对比）
- [ ] 接入大模型 API（需求解析、智能匹配、文案生成）
- [ ] 接入持久化存储（数据库）
- [ ] 50 题评测集与评测报告
- [ ] 部署上线并邀请同学内测

## 技术栈

- Next.js 15（App Router）+ React 19 + TypeScript
- Tailwind CSS 4
- 数据暂存在浏览器 localStorage，便于快速验证产品流程

## 本地运行

```bash
pnpm install
pnpm dev
```

打开 http://localhost:3000
